# attentionEconomist

Attention Economist is a Chrome extension designed to help you stay focused while browsing the web. It allows you to temporarily block the webpage you're currently viewing. 


# Installation

Download or clone this repository.

Open Google Chrome.

Go to chrome://extensions.

Turn on Developer mode.

Click Load unpacked.

Select the Attention Manager project folder.

The extension will now appear in your Chrome extensions.

# How to Use
Block a Website

Open the website you want to block.

Open the Attention Manager extension.

Click Block Website.

The page will be covered until the one-minute block ends.

Unblock Early

If you want to leave the block early:

Click Unblock Website.

Click the button 70 times.

The page will then become available again.


# Requirements

A desktop environment that supports Chrome extensions
